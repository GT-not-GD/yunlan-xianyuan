# 云岚仙缘 · AI 跑团提示词包

> 修仙 Galgame × 严格跑团 × 任意 AI 主持人。
> 规则托管在本仓库：AI 一条**启动指令**即可下载规则、开局主持。全文字、零算力、零 API 费用。

## 🚀 三步开局

1. 打开任意**支持联网**的 AI 聊天（ChatGPT、DeepSeek 联网版、Kimi、Gemini、豆包……）
2. 复制 [`BOOT.md`](./BOOT.md) 中方框内的启动指令，粘贴发送
3. AI 下载规则后会请你确认角色名 / 出身 / 功法，掷骰开局——之后像跑团一样输入任意行动即可

⚠️ **本仓库必须保持 Public（公开）**，否则 AI 无法免登录下载规则。

## 🎲 玩法概要

- 主角入云岚宗修行，攻略 **苏凝霜**（冰山剑修大师姐）与 **药灵儿**（炼丹小师妹）
- **严格跑团**：掷骰公开透明（如【判定 d100=47 ≤ 60 成功】），修炼 / 突破 / 战斗 / 炼丹全有公式
- **主线**：第一季「鼎中天」十章 → 季终 Boss（天衡+大寂灭先锋）→ 三抉择 × 四感情线 = 12 结局 → 飞升开启第二季，季季相承、超长线运营
- **存档码**：说「存档」拿一行文本，换设备、换 AI 都能续玩

## 🔥 规则热更新

直接在 GitHub 网页编辑 `rules.md` 并提交，AI 下次下载即为最新版——无需通知玩家重新粘贴。

## ❓ FAQ

- **AI 说无法访问链接？** 用备用方案：手动粘贴 `rules.md` 全文。
- **AI 数值乱了？** 发送「校准」，让它重新核对状态栏。
- **想换女主 / 世界观？** 编辑 `rules.md` 第四节「世界观与角色」。
- **想调难度？** 开局时加一句「突破率 -10%」或「恋爱喜剧浓度加倍」。
